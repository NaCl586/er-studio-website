# ER Studio Company Profile Website

Starter implementation based on the provided ER Studio mockups.

## Structure

- `index.html` — Home
- `games.html` — Games
- `services.html` — Services
- `about.html` — About Us
- `news.html` — News
- `css/style.css` — shared styling
- `css/pages.css` — page-specific styling
- `js/main.js` — navigation, shared interactions
- `js/games.js` — games page data/carousel
- `js/news.js` — news cards

## Running locally

No server is required for the first version. Open `index.html` in a browser.

For a better development workflow, use VS Code with the Live Server extension.
